SETUP
- Copy .env.example to .env and fill in your own values.
- Required: MONGODB_URI and JWT_SECRET (at least 32 characters).
- Optional: PORT, NODE_ENV, JWT_EXPIRES_IN, CLIENT_URL, ADMIN_NAME, ADMIN_EMAIL, ADMIN_PASSWORD.
- Never share or commit .env. This ZIP intentionally excludes the original .env.
- From this server folder run: npm install
- Then run: npm run dev
- Health check: http://localhost:5000/api/health

VALIDATION
- All JavaScript files passed `node --check`.
- A live MongoDB/API integration test was not run here because no private database credentials were used.
- Review your local .env and run the API tests after installation. Frontend request payloads must use `departmentId` when approving a complaint.
